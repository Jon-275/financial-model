Get started

Try the example first.

Use fictional figures to learn the workbook. Then save a separate copy for your own plan.

Follow the guided example

  1. Open a private copy

    Download the workbook and keep its .xlsm format. From Start Here, open Inputs and select Example plan.

  2. Compare retirement ages

    Read the base plan on Summary. Return to Inputs, choose Retire at 65 and open Summary again. Check the planned retirement age and whether the bills are covered through age 95.

  3. Explore market risk

    Review assumptions and use 100 paired paths while exploring. Wait for “Risk results are current” before interpreting the run.

  4. Keep your report

    Choose Dollar view on Summary. In File → Print, select Active Sheets with only Summary selected. Preview all six pages before printing or saving a PDF.

Which Excel version can I use?

Version 1.0.0 was verified on desktop Excel for Mac 16.115. Windows is unverified. Excel for the web can display saved results but cannot run market analysis. Keep calculation set to Automatic.

Do I need to enable macros?

Run market risk requires macros. Follow your organization’s policy. You can review the base projection before running risk. If navigation buttons do not work, select the sheet tabs directly.

How long does market analysis take?

Use 100 paired paths for exploration and 1,000 for a final report. Runtime depends on your Mac and plan. Progress appears in Excel’s status bar. See measured Mac runtimes.

Who does the tax model cover?

It estimates US federal and California taxes for couples filing jointly, with selected surviving-spouse assumptions. It is an educational model. Results depend on your inputs, assumptions and the documented limits.

Where do my personal figures go?

You enter figures into your own workbook copy. This landing page has no input form or analytics. Keep your personal workbook and report private; use fictional figures when asking for help on GitHub.
